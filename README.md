## 📖 Overview

**Pilgrims' Stack** is the ultimate desktop application designed to streamline operations for Hajj agencies. It replaces messy spreadsheets and disorganized files with a fast, secure, and intuitive local database interface. 

### ✨ Key Features
- **100% Offline & Secure:** Your agency's data and sensitive pilgrim documents never leave your computer. Total privacy with a blazing-fast local database.
- **Smart Bulk Management:** Select multiple pilgrims at once to update registration statuses, toggle genders (M/F), assign tags, or delete records seamlessly.
- **Document Tracking:** Upload, preview, and manage Profile Pictures, Passports, Birth Certificates, and NIDs instantly.
- **One-Click Printing:** Generate beautiful, printable tabular reports of your pilgrim lists (including photos)—perfect for embassy submissions.
- **Seamless Backups:** Create complete standalone backups of your entire database and documents with a single click, and restore them to any PC.

## 💻 System Requirements

- **Operating System:** Windows 10 or Windows 11 (64-bit)
- **Internet Access:** Not required (100% offline functionality).
- **Storage:** Minimal footprint (data and documents are stored locally on your device).

## 🚀 Installation & Usage

Since this is a closed-source commercial product, the source code is not publicly available in this repository.

1. Go to the [Releases](../../releases) tab of this repository.
2. Download the latest installer: `Pilgrims' Stack Setup 0.1.2.exe`.
3. Run the installer and follow the setup wizard.
4. Launch the application from your desktop or start menu.
